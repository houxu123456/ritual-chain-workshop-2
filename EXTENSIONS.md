# Extensions & Future Improvements

While reviewing the workshop code, I noted several directions for personal extension once mainnet is live:

1. Simple frontend (Next.js + wagmi) to create markets and place bets
2. Event indexing for better market history display
3. Support for more complex jq filters
4. Optional short dispute window after resolution
5. Batch claim function for users with multiple winning positions

These are planned as next steps after mainnet launch.  
Current focus remains on understanding and validating the core autonomous resolution logic.
